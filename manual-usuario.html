Manual del usuario

Guía de uso del sistema de riego inteligente AgroSmart IoT

Este sistema permite monitorear, controlar y automatizar el riego agrícola de forma visual y sencilla. Está pensado para que operarios, administradores y técnicos puedan supervisar la humedad del suelo, activar la bomba, definir umbrales y revisar el historial de eventos sin complicaciones.

1. Inicio de sesión

Accede con tus credenciales del sistema o usa las credenciales demo para probar la plataforma.

2. Monitoreo inteligente

Observa la humedad del suelo, el estado de la bomba y el estado del depósito de agua.

3. Automatización

Configura umbrales, modos de operación y horarios programados para riego eficiente.

4. Historial y alertas

Revisa eventos, errores y actividades pasadas para decidir mejoras y mantener el sistema estable.

1. Acceso al sistema

El sistema requiere iniciar sesión antes de ingresar al dashboard. La pantalla principal incluye una vista de autenticación con dos opciones: Iniciar sesión y Registrarse.

Proceso recomendado

  1. Escribe tu correo electrónico.
  2. Ingresa la contraseña correcta.
  3. Marca “Recordar sesión” si deseas mantener el acceso activo.
  4. Haz clic en “Ingresar al Dashboard”.

2. Comprendiendo el dashboard

Cabecera principal

  • Selector de lugar o finca.
  • Indicador del estado del sistema.
  • Botón de acceso al manual de usuario.
  • Perfil del usuario actual.

Panel principal

  • Lista de zonas de riego.
  • Información del lugar seleccionado.
  • Estado de humedad del suelo.
  • Estado de la bomba y control manual.
La parte central del dashboard muestra en tiempo real la humedad actual de la zona seleccionada, el modo de funcionamiento y si la bomba está encendida o apagada.

3. Gestión de lugares y zonas

Registrar un nuevo lugar: usa el botón “+” junto al selector de lugar para añadir una finca, invernadero o parcela.
Crear una zona: en la barra lateral pulsa “Nueva Zona” para definir un área específica con un cultivo diferente.
Seleccionar zona: haz clic sobre una zona en la lista para cambiar la vista y tomar decisiones sobre ese cultivo.

Ejemplo: una finca puede tener varias zonas como “Zona 1 - Tomates”, “Zona 2 - Pimientos” y “Zona 3 - Maíz”, cada una con sus propios parámetros.

4. Modo de operación y configuración

Modos

  • Automático: el sistema activa o desactiva el riego según la humedad detectada.
  • Manual: tú decides cuándo encender o apagar la bomba.
  • Programado: se activan horarios de riego definidos previamente.

Umbrales

  • Humedad mínima: si el suelo cae por debajo de este valor, se activa el riego.
  • Humedad máxima: cuando llega a este valor, la bomba se apaga.
  • Duración máxima: límite de seguridad para evitar riego excesivo.
  • Frecuencia de muestreo: intervalos con los que se lee la humedad.
La lógica principal del sistema usa histéresis: activa el riego cuando el suelo está seco y lo detiene cuando vuelve a alcanzar un nivel adecuado.

5. Sensor de humedad y bomba de agua

Indicador de humedad

El medidor muestra el porcentaje de humedad del suelo. El esfuerzo del sistema es mantenerlo dentro del rango definido para cada cultivo.

Si el valor es demasiado bajo, se puede activar la bomba; si es demasiado alto, se detiene el riego.

Control de la bomba

En la tarjeta de la bomba puedes encenderla o detenerla manualmente. También puedes simular condiciones de vacío del depósito o activar el modo de secado para probar el comportamiento del sistema.

6. Horarios programados, alertas e historial

Horarios programados

Desde la pestaña “Horarios Programados” puedes configurar turnos de riego automáticos por hora y días de la semana.

Esto es útil cuando el usuario desea un riego regular aunque el sensor no marque niveles críticos.

Alertas

El sistema genera avisos cuando ocurren eventos importantes como:

  • Depósito de agua vacío
  • Timeout del perro guardián
  • Fallo de seguridad del sistema

El historial de eventos guarda la duración del riego, la humedad inicial, la final y el tipo de activación, para que el operador pueda revisar el comportamiento pasado del sistema.

7. Solución de problemas y buenas prácticas

Si el sistema no riega: revisa que la zona esté seleccionada y que el modo de operación no esté en “Manual” con la bomba apagada; también verifica que el depósito no esté vacío.
Si la humedad no cambia: comprueba que el valor del rango de simulación o los parámetros de control estén configurados correctamente.
Si aparece una alerta de seguridad: revisa si la duración máxima del riego fue excedida o si el depósito perdió agua.
Buenas prácticas: define valores realistas según el cultivo, revisa alertas regularmente y programa riegos de acuerdo con la etapa de crecimiento.

8. Resumen del flujo recomendado

  1. Inicia sesión en el sistema.
  2. Selecciona la finca o lugar correcto.
  3. Elige la zona que deseas supervisar.
  4. Revisa el porcentaje de humedad y el estado de la bomba.
  5. Configura los umbrales y horarios.
  6. Verifica alertas e historial para confirmar el funcionamiento.
